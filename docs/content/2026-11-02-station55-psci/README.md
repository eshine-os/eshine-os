# 站 55:PSCI 补面+量子会计(内容包口径)

## 一句话

VM 从"只会被处决"到"会自己关机、自己重启"——PSCI 四函数补齐,
外加每 VM 的泵量子账。

## 技术叙事

1. **干净关机**:SYSTEM_OFF 走 VM_DEAD 不走 fault 路径——关机是
   生命周期事件,不是事故。
2. **复位链**:SYSTEM_RESET = teardown + 重建 + 重启,复位旗在
   泵出口消费——重启是三段式,不是一步跳。
3. **量子账**:每个 VM 跑了多少泵量子,vmstat 一行可见——先记账,
   后执法(消费者召唤再上强制)。

## 金句

- 关机和事故死是两种死:一个没有 fault 行。
- 重启是 teardown、rebuild、restart 三兄弟,不是一个跳转。

## 数字

- 门禁 157→161;冒烟 25/25;四 PSCI 函数+per-VM 量子计数。
