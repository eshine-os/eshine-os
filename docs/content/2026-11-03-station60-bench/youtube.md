# YouTube 分镜(站 60 延迟基线)

标题:唤醒延迟直方图——一拍的超睡,和一场号面事故

## 分镜

1. **冷开场(0:00-0:40)**:直方图实机输出滚动(200 环,9-10ms
   主簇)——"这个数字为什么恰好是一拍?"
2. **机制(0:40-2:30)**:POSIX 至少语义 × tick 量子=ceil+1 拍界;
   相位锁定演示(主簇为什么紧);相位游走=尾部双拍。
3. **号面事故(2:30-4:30)**:全零直方图+rc=-1+errno=38 三连信号;
   反汇编注记翻车;musl 头一行定案(35=x86_64,101=asm-generic)。
4. **亚拍面恒零(4:30-5:30)**:0-1ms 桶零=tick 调度器的诚实;
   hrtimer 后弧账。
5. **基线纪律(5:30-6:30)**:数字非门;形状+上界门;后续站对照
   主簇位移;门禁 [175-176] 收口。
