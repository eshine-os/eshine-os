# 站 60:延迟基线(内容包口径)

## 一句话

第一个性能测量站:周期任务的唤醒-运行延迟直方图——数字不是门,
形状才是。

## 技术叙事

1. **一拍的超睡**:nanosleep 的 POSIX 至少语义在 tick 量子调度器上
   = ceil+1 拍界——200 环实测主簇 9-10ms(恰一拍减 30µs 相位),
   25% 相位游走越拍界(双拍)。
2. **号面事故**:首版 syscall 号臆 35(那是 x86_64 的)——直方图
   全零、errno 38 三连信号才把 asm-generic 真号 101 挖出来。站 42
   的定号纪律(musl 头为准)重犯一次。
3. **亚拍面恒零**:0-1ms 桶零——tick 调度器没有亚拍唤醒,hrtimer
   是后弧的账,不假装。

## 金句

- 数字是基线,不是门:门在形状和上界,不在跑分。
- 号面必读头文件:三连信号(全零直方图+rc=-1+errno=38)比反汇编
  注记可信。

## 数字

- 门禁 174→176;冒烟 11/11;200 环,主簇 9-10ms,max=10054µs。
