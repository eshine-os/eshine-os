# 站 54:跨域 fail-closed 门(内容包口径)

## 一句话

共享窗从"建了就能访问"变成"宿主说能访问才能访问"——撤销一个
stage-2 表项加一发 TLB 广播,越权访问当场隔离死。

## 技术叙事

1. **ACL 即表项**:授权的物理实现就是那个 2MB 块描述符——清掉它,
   访问变翻译故障;建回来,访问恢复。
2. **运行时改表三纪律**:dsb 前置→TLBI IPAS2E1IS 内广播→dsb+isb
   收口——这是 demand paging 和内存气球技术将来的入场券。
3. **默认拒绝不动**:越权访问走既有的 guest_fault 隔离死路径,
   fail-closed 靠的是映射的存废,不是新增检查点。

## 金句

- 最硬的权限门是页表项本身:有它就有路,没它就是墙。
- 改表三纪律不是仪式,是跨核一致性的最小代价。

## 数字

- 门禁 154→157;冒烟 21/21;单块条目改表+一发 TLBI。
