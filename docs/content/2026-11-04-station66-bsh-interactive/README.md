# 站 66:bsh 无参交互(内容包口径)

## 一句话

深水三镜取证:vm0"定格"90% 是设计静默,真断是泵的 RX 注入门——
修真后交互链首次点亮,但非确定竞态挂 58 挂脸族的账。

## 技术叙事

1. **第四镜**:gdb-multiarch 源级直读(符号直读 vm/vcpu/任务池/
   调度队列/客 RAM)——全案靠它定谳,顺带废了 HMP xp 读 MMIO
   (对照实验:正常态与定格态同值=假象)。
2. **翻案**:vm0 根本没死(tick 活/心跳循环活/ash 合法睡 stdin),
   "定格"的主谋是站 24A 的心跳静默门——设计行为背了锅。
3. **真断**:泵的设备注入门 `wr==TIMER && owner==v`——ash 睡 stdin
   时 RX 中断进不来。修:RX 环真有可取数据(过门控)也醒。

## 金句

- 静默不等于死:先读设计门,再谈机制雷。
- 探针的对照组是一切结论的地基——对着坏仪器的取证是空对照。
