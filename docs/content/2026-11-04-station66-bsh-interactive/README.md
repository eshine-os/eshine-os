# 站 66:bsh 无参交互(内容包口径)

## 一句话

深水三镜定谳后定稿行 REPL:壳父自读行+每行一个 sh -c——
用几十站验证的稳定输入面绕开常驻 ash 的非确定竞态。

## 技术叙事

1. **第四镜**:gdb-multiarch 源级直读(符号直读 vm/vcpu/任务池/
   调度队列/客 RAM)——顺带废了 HMP xp 读 MMIO(对照实验=假象)。
2. **翻案**:"定格"90% 是站 24A 心跳静默门的设计;真断是泵的
   33 注入链(owner 面+TIMER 泊排除)。
3. **修真+定稿**:泵门放宽点亮过常驻 ash("sh: not found"铁证)
   但 1/4 活率——定稿 REPL:稳定面(壳读行)组合确定性面(sh -c),
   活率 3/4(唯余 58 族挂脸靴)。

## 金句

- 绕开竞态的最稳办法不是修好它,是把路径换到已验证的稳定面上。
- 静默不等于死:先读设计门,再谈机制雷。
