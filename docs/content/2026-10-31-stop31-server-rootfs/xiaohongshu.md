# fd 不是整数,是通往服务器的通道 🔌

造 hypervisor 第 31 站:server+rootfs 落地,88 门 ×2 双绿✅

fd 到底是什么?
Linux 给你一个整数,微内核给你真相:
{coid, ocb} 通道三元组——
coid=连到哪个服务器的通道(路由面)
ocb=这一打开在服务器侧的状态(状态面)
open/read/write/close 没有一行直接碰文件,
全部是三段消息往返,这就是 QNX resmgr 模型🎭

rootfs 是真 cpio(newc):
110B 头+13 段十六进制域+TRAILER 收卷
构建期打包,内核解析,归档落内核区——
用户窗看不到,文件只能经消息拿到🔒

POCB 引用计数双侧镜像:
fork 继承 fd → 客户端 coid 引用+1
同时发 DUP 消息 → 服务器 ocb 引用+1
单侧只加一半?父先退出释放 ocb,
子的 fd 指向已回收号,再开同号=
两家的文件位置互相串写💥

开机链固定序列:
tty 服务器→ramfs 服务器→PM
PM 绑 stdio 0/1/2 后退场——
参考实现 PM 形状,"固定序列起步+协商位留后"📖
