# 站29 口径:每个进程一个世界

**eshine-os** · 站 29(进程+地址空间)· 2026-10-31

## 本站做了什么

EL0 从"全体用户共享一段恒等内存"升格为**每进程地址空间**:

- **每进程自持页表**:L0/L1/L2 三级表每进程一份,任务切换点随
  任务装 TTBR0,ASID 位图分配,TLB 靠 ASID 标签跨切换存活;
- **缺页上岗**:EL0 访问未映射页不再"诚实收尸",而是查本进程
  的 VMA 申报表补页——镜像/栈补恒等页,匿名 mmap 补零页,原地
  重执行;申报外的野访仍走终态面,边界不松;
- **进程生命周期三态**:CREATE 挂起、fork(COPY_UCONTEXT:eager
  全拷,子进程拿到物理隔离的页池副本)、EXEC_SETUP(**帧改写式
  exec——内核只改 pc/sp/x0 七个字的保存帧,零镜像字节知识**)。

## 一个设计自抓

首版把"页池"和"用户 mmap 窗"设计成同一 VA 区——fork 的内核态
页拷贝立刻撞墙:拷贝目标在内核 PGD 上不可达。翻案成 VA 分区:
页池自任"内核高半区"(所有地址空间恒驻 EL1,用户永不可见),
mmap 另立专窗。一次重设计消掉整类可达性问题——**地址空间设计
的第一课:先画"谁在哪个语境能看到哪块",再写第一行映射**。

## 两个自雷(复现器当晚抓回)

- exec 的 arg=0:syscall 分发器的"返回值写 x0"回写把帧改写的
  arg 覆掉了。修=exec 返回 arg——新语境的 x0 本就是"返回值",
  一字两用;
- 门锚带 `\n` 撞串口 `\r\n`:判据锚先在串口实貌上过一遍。
