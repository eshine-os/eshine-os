# 站 56:DFX 收口(内容包口径)

## 一句话

观测面的最后三块拼图:迹环会按 CPU 过滤了、每个 VM 的抢占有了
账本、三笔"两仓同病"的老账定谳归档。

## 技术叙事

1. **查询面**:vmtrail 从"全量倾倒"到"[N] [cpu0-3]"过滤——
   取证不再需要翻十六万行。
2. **双会计**:每个 VM 的抢占数和量子数,vmstat 两行——先看见,
   再谈治理。
3. **自审定谳**:三笔审计遗留病(量子补偿/握手原子性/FP eager)
   逐件给出"记档还是修"的结论和理由——不修的也要说清为什么。

## 金句

- 观测的终点不是"什么都能看",而是"想看什么就只看什么"。
- 老账不清,新账不断——每笔"记档不修"都要有理由在案。
