# X 8 推(站36 shm+xspace)

1/8
eshine-os 站36:共享内存日。站29 的 fork=eager 全拷,物理隔离即其存在意义;今天补共享面——关键设计一句话:共享是 VMA 的一个类型,不是全局开关。SHM 型 fork 不拷、子表同物理直挂;其余 VMA 照旧全拷。共享与隔离,同一张表里分型两立。 #embedded #kernel

2/8
xspace 固定窗:块 8 @0x41000000,段 i 固定映同一 VA——同段在任何进程同 VA。参考实现调研时"全局唯一共享 VA 窗口"的机制白描,今天落成我们自己的形状(零代码红线:机制参考,不搬代码)。 #ARM64

3/8
本站最想聊的纪律:页归属。段页从页池取出的那一刻,所有权转给段注册表。fork 不拷它、munmap 不碰它、退场不回收它——唯一还池入口是 destroy,destroy 要 refs=0。一条铁律管三条回收路,泄漏和双释放都不可能出现,因为只有一口井能倒水回去。 #engineering

4/8
单拷窗(参考实现 VM_SET 的 v0 兑现):1KB 载荷走共享窗=一拷,线上只发 8 字节脉冲携带段号引用;接收者按引用 attach 后原地零拷读。参考实现的真身是"免页表遍历的单拷+延迟访问"——不是零拷贝魔法。在我们的机器里"免遍历"甚至天然成立:页池恒驻,同物理直挂,无 walk 可省。 #RTOS

5/8
冒烟抓的竞态:父验证完立刻 destroy,子进程还没退场完(fd 关闭走消息往返,比父的验证路慢),refs=1,-EBUSY。修法朴素:销毁前先等持有者死透。生命周期对象的老规律,每个新面都会再教你一次。 #lessons

6/8
[90] 门判据是个判别器:子进程写共享 VA,父收尸后读回——如果 fork 偷偷拷贝了,子写被私有化,父读到 0,直接判负。判据会撒谎的问题,要让判据自己给出反例。 #testing
