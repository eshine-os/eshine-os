# 站36:共享内存日 📦(页归谁管,一条铁律)

给自己的 RTOS 补上共享面。前面站 29 的 fork 是
**eager 全拷**——物理隔离就是它的存在意义;今天加
共享,关键是:**共享是 VMA 的一个类型,不是全局开关**。

✅ VMA 第三型:SHM(共享段)
✅ xspace 固定窗:段 i 在任何进程同 VA
✅ fork 律:SHM 段子表同物理直挂零拷贝,其余照旧全拷
✅ 单拷窗:1KB 载荷走共享窗,线上只发 8 字节段引用
   (参考实现 VM_SET 真身=单拷+延迟访问,不是零拷贝魔法)

## 页归属铁律 🔑

段页从页池取出的那一刻,所有权转给段注册表:
- fork 不拷它(挂同页)
- munmap 不碰它(SHM 段拒绝,路由专用 detach)
- 退场不回收它(只扫私有块)

**唯一还池入口=destroy,destroy 要 refs=0。**
一条铁律管三条回收路——泄漏和双释放都不可能出现,
因为只有一口井能倒水回去。

## 判据会撒谎?让判据自己给反例 🧐

[90] 门的判据是个判别器:子进程写共享 VA,父收尸后读回
——**如果 fork 偷偷拷了,子写被私有化,父读到 0=判负**。

顺手抓的小雷:父验证完就去 destroy,子还没退场完
(fd 关闭走消息往返比父慢),refs=1→-EBUSY。
修法朴素:销毁前先等持有者死透😄
