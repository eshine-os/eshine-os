# 站 62:版本 pin+SBOM 台账(内容包口径)

## 一句话

SBOM 收口:八组件一台账,机器可读、脚本校验、NOTICE 聚合——
账本的完整性是可以执行验证的属性。

## 技术叙事

1. **两副面孔**:LEDGER.md 给人读,manifest.yaml 给机器读——
   同一张表,两种消费。
2. **版本 pin**:in-repo 工件名必须含钉死版本(musl-1.2.5.tar.gz
   的 1.2.5 就是承诺);GPL 组件恒仓外。
3. **可执行的完整性**:sbom-check.py 五面校验(字段/工件/pin/
   隔离/NOTICE),全绿才 0 退——台账不是文档,是被门禁消费的代码。

## 金句

- 台账的完整性是可执行属性:五面全绿才退 0。
- prebuilt 也是账:gcc/binutils/qemu 版本实采集,非记忆。

## 数字

- 门禁 178→179;8 组件(3 in-repo/5 out-repo);五面校验。
