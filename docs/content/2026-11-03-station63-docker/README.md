# 站 63:docker 弧(内容包口径)

## 一句话

工具链的运输形态:Dockerfile 钉链镜像+版本对账(容器实采 vs 台账 pin
逐字相等)+发布 tar 可解包即靴——同一棵树,任何机器,同样的二进制。

## 技术叙事

1. **同源即同 pin**:容器基座 ubuntu:24.04 与宿主同源,apt 交付的工具链
   版本与 SBOM 台账的 pin 天然一致——但一致不是假设,是判据:容器内
   -dumpfullversion 实采逐字对账。
2. **镜像层零仓字节**:源树挂载 /src 以宿主 uid 降权跑,产物落宿主树,
   镜像只运输工具链不运输代码。
3. **发布=可解包即靴**:部署四件+run 入口+工件账+合规面打 tar;自靴
   判据在打包脚本尾部现场重演 musl hello 全链。

## 金句

- pin 是对账出来的,不是注释出来的。
- 镜像运输工具链,不运输代码。

## 数字

- 门禁 179→180;四件+run.sh+manifest 打 tar;容器内全链重建+sbom 全绿。
