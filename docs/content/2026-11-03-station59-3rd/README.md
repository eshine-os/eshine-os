# 站 59:生态件入仓(内容包口径)

## 一句话

第三方组件开始有账可查:cJSON 和 zlib 进仓、进 demo、进台账——
SBOM 的第一页从今天写起。

## 技术叙事

1. **入仓即记账**:3rd/LEDGER.md 六列表(名/版/许可/形态/源/用途),
   append-only;GPL 仓外隔离(busybox 先例)——许可政策从口头变文件。
2. **生态件住 EL0**:cJSON/zlib 都是 musl 世界的 demo 消费者
   (jsontest 解析治理面真清单;ztest 做 slog 压缩落盘回读);RTOS
   内核的自研最小 JSON 不动——站 51 的决策不翻案。
3. **配方直编**:单文件库直编、zlib 核心源直编——交叉语境下
   configure 是负债不是资产。

## 金句

- SBOM 不是文档任务,是入仓纪律:一行台账,先于一个 tarball。
- 生态件住 EL0:内核的自研面越稳,生态的引入越安全。

## 数字

- 门禁 171→174;冒烟 10/10;台账 4 组件(busybox 仓外)。
