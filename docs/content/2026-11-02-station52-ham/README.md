# 站 52:ham 健康面(内容包口径)

## 一句话

治理面管"服务怎么起",健康面管"服务活着没"——心跳实体两拍不吭声
就 MISSED,warn 落卷留痕,补拍即恢复。

## 技术叙事

1. **心跳即契约**:每个实体声明自己的期望拍距,两倍周期无声=失联
   ——阈值是数据,不是散落的超时魔法数。
2. **动作即日志**:missed 与 recovered 都走 elog 契约环、落 /var/log
   ——健康事件和其他日志同一根神经,同一份档案。
3. **三站合链**:契约层(站 49 说)、持久层(站 50 记)、健康层
   (站 52 看)在一个判据里合卷。

## 金句

- 治理面回答"怎么起",健康面回答"还活着吗"——两个问题,两套机制。
- 健康事件不是另一类日志,是同一根神经上的一根手指。
