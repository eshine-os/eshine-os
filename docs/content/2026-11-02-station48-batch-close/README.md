# 站 48:批收口站(内容包口径)

## 一句话

六站连开的最后一个"站"不是新机制,是把批内四面合成一屏自证
(health),外加一份诚实的发布注记——收官也是交付物。

## 技术叙事(对外讲什么)

1. **health 面板**:一屏 uptime/任务/进程/fp 计数/分区/崩溃环/
   跨 VM 窗——批内四个观测面(站 43/45/46/47)的合卷。观测
   不越域:每个数字由源模块就地出数,面板只做拼版。
2. **发布注记**:六站战果表+六枚战雷+记档差异;版本号不动,
   因为发布节奏归用户——工程替用户记账,不替用户做决定。
3. **批收官的形状**:批令(六站写而不跑,收官统一两连)让
   工程节奏从"站站庆功"变成"战役收官"——门禁 123→133,
   冒烟 6/6→14/14 累进。

## 金句

- 收官站交付的不是新机制,是"知道自己交付了什么"的能力。
- 工程替用户记账,不替用户做决定。
