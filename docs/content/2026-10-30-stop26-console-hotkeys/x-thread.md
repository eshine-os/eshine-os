# 站 26 X 串(8 推):串口上找一个没有主人的键

**1/8**
需求看着很小:给我的 Type-1 hypervisor 加个快捷键,在三个 VM
(vm0 RTOS / vm1 裸机 / vm2 Linux)的 shell 之间直接切换。
认真选键才发现:串口键位表几乎全满——每个控制键都已经有主
了。这篇讲怎么排雷选型。 🧵

**2/8**
先列不能动的:0x1d(Ctrl-])是逃生字符——宿主夺回控制台的
唯一后门,三站门禁、所有探针、肌肉记忆全锚定它。快捷键设计
的第一条铁律:**不撕毁既有契约**。

**3/8**
再列不能偷的:Ctrl-C=SIGINT(归 Linux tty)、Ctrl-D=EOF、
Ctrl-\=SIGQUIT(busybox 真信号)、Ctrl-Z=SIGTSTP、其余大多被
行编辑占着。偷任何一个都破坏 guest 的"真实计算机"体验——
而这系统的卖点就是 guest 跑真 Linux 真 busybox。

**4/8**
最后列不能用的:F 键/方向键=多字节转义序列,裸串口上与
vi/bash 的 ESC 用法无法无歧义区分;Alt+数字(ESC+数字)同理
——vi 用户先按 ESC 再按 3,你就误切了。

**5/8**
数完剩两个真无主的:0x1e(Ctrl-^)和 0x1f(Ctrl-_)。定案
**0x1e**,三个理由:①与 0x1d 字节相邻——"] 夺回宿主,^ 跨
VM 直切"一对心智模型;②无 TTY 信号绑定,三客零成本;③
QEMU Ctrl-A / tmux / screen 验证过的前缀键形态。

**6/8**
语义抄 QEMU 同律:Ctrl-^ 0|1|2 切 vm,h 回宿主,双击=字面
直递,**未绑定键=前缀取消、本键照常处理(一个字节都不吞)**
——误触零损坏。冒烟实证:Ctrl-^X 后接 "hb",X 直达 guest,
RTOS 把 "Xhb" 当未知命令回了 usage——取消路径零损坏的活证。

**7/8**
实现两个原则:①把 vmconsole 命令体原样抽成公共函数,快捷键
与手打命令**零行为差异**(拒绝不夺台/唤醒/冲刷次序全同);
②单字节前缀态机+fall-through——双击字面不需要专门代码,第
二个 0x1e 清前缀后自然落入站 24 推环唤醒不变量全路径,零
goto 零复制。

**8/8**
门禁 79→80:新门 [77] 一窗全验四次切换+hb 回复(热键切换后
输入链完整)。顺移自抓一折:新门最后一步把控制台收归宿主,
下游旧门开头的逃生步骤扑空超时——**在流程中间插新门,新门
改变的世界状态会让下游旧门的隐含前提失效,不只是改编号**。
终树双绿 80/80 ×2。
