# 第二十五站内容包:唤醒架构专站(可达性翻案 / 法医双位 / 仪器战争三重奏)

口径(README 索引):
- **A 可达性翻案**:站二十四登记的头号残余"[41] vtimer 侧
  死亡帧(TIMER+ctl=0 稳态泊)"被静态证明**不可达**——泊位
  分类与出口存档同拍同字段读 ctl,稳态必然自洽;guest 有合法
  自缴械习语,那帧取证是健康态被误读。**原 B 块修复=死代码
  不落码**(站二十二纪律:证明先于代码)。
- **B 仪器化**:64 槽迹环只余 0.1s 历史(所有 dump 都只是
  即时尾巴)——扩 16K≈27s 窗;取证主链收编锁纪律(环专用
  递归自旋锁杀丢更新/幽灵槽,证据行整行持锁防撕);**法医
  双位**:verify 门红自动取证(全类失败脸)+CARM-STALL
  (consume-fail 活锁的常设绊线);初版绊线被评审证明真阳性
  为空+假阳性可达,**砍除**。
- **C 泵扫级 vtimer 兜底**(真实可达的延迟类):泊定帧唤醒
  只押 IRQ 驱动 sweep,介入运行者装回自己 ctx 即蒸发泊者的
  27——唤醒迟至 1Hz 扫描=tick 迟到 ≤1s;泵扫直查 saved
  cval 置 WOKE,迟到 ≤1 泵圈。pending⇒runnable 至此在全部
  四类可交付事件上泵扫级成立。
- **仪器战争三重奏(本站最大战果是诚实战报)**:C 臂落地后
  普查报"6/6 确定性输入蒸发",误判"C 臂回归是我"——全量
  16K 取证翻案,臂无罪,三重仪器伤:①探针窗界正则(chardev
  ~16B 分块劈在窗界,每发必失,"确定性"是分块模式的确定性);
  ②宿主并发争抢(普查与 29 代理评审并发,guest 掉至 6-18%
  模拟速度);③QEMU chardev 投递滞后(ev9 整组缺席=字节
  根本没进超级监控器,失败在上游)。**唤醒架构被自己的仪器
  洗清;对着坏仪器做的 A/B 是空对照。**
- **R-e 重审翻案**:门禁 [36] 一折"运行态 tick 停发"初判
  **撤回**——R-e 轮与评审工作流并发(宿主争抢),3.0s 的
  demo 在 6% 速度下必超 20s 窗,签名与伪象完全相容。教训
  入律:门禁一折先查宿主负载,再谈机制。
- 评审:29 代理/26 findings→13 CONFIRMED/13 REFUTED 全折叠;
  门禁 **79 不变,终树双绿(79/79 ×2)**,CARM-STALL 零触发。
- 方法论:**判据先于结论,仪器先于判据;新探针必须先在已知
  好世界验证,再做差分。**
