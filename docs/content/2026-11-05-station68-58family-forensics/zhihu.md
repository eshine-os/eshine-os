# 追了十四个站的"随机挂死",真凶是每靴第一拍就混进就绪队列的 idle

(知乎长文口径)

## 一个"玄学"Bug 的档案

eshine-os 的 vm0 有个老毛病:引导 20-75% 概率挂死。死法有
三种,像三种病:静默楔(死得无声无息)、内核 panic(打印出
的 ELR 竟是一个任务池数据区的地址)、以及最诡异的——串口喷出
8.4MB 纯空格,以精确的 128 字节周期,没有换行,没有别的字节。

更早的交互式 shell 也有四分之一的概率"卡住"。这些脸 shared
同一个犯罪嫌疑人画像:非确定、负载敏感、带 gdb 调试就不复现。

今天专门开了一站,把这族案子从头办到尾。

## 先修镜子,再办案

QEMU 的 gdb stub 有个坑:VA 读要走"当前 CPU 的翻译体制",
在 EL2 语境下客户内存全读空——前几轮取证全部扑空,一度以为
是探针自身的问题。三把新钥匙后局面打开:

- `monitor xp` 走 HMP 物理读,绕过翻译体制;
- **monitor 的输出在 stderr**,不在 stdout(我们的解析脚本三
  度全灭才抓到这个);
- 每靴轮换 gdb 端口,TIME_WAIT 竞态曾让整轮数据变成假象。

镜子修好,三例活体解剖立刻有货:panic 靴的 ELR=0x40188f50,
查符号表——无符号,因为那根本不是代码,是**任务池第 5 槽的地
址**;静默楔的主核停在 guest_park,rt_ticks 冻在 8(80ms 就死
了);洪水靴死在 hello 第一个 printf 的 "pid=" 处,后面全是
空格。

## 仪器化:与其碰运气,不如埋守卫

活体解剖靠等,等来的标本还常常不是想要的那个。换个思路:
把体检做进 tick——每个时钟拍扫描全任务池,四个谓词:

1. 任务的 sp 必落自身栈域;
2. EL0 任务的 ksp 必恰等于创建时的内核栈顶;
3. READY 任务必须能在其就绪队列链上走达;
4. 队列链全审计:链野/幽灵/环/尾脱链四类分类。

外加一个 writev 绊线盯洪水脸。任何谓词被打破,10ms 内带全
证 panic:受害者、毒值、期望域、双核当前任务、tick 数。

## 守卫开火:真凶在案

第一次开火,打在 gated 的 fork 子身上:sp 被写成了蹦床域的
帧地址。第二次开火,四元证据说得更直白:

```
queue poison: cpu 0 prio 31 wild 0x4015e460
cur0=&pool[0] cur1=idle1 ticks 1
```

0x4015e460 是 **idle 任务的地址**。它在 tick 1——每靴的第一
拍——就出现在了就绪队列的 31 优先级层里。

回放案发:IRQ 出口的调度代码,把被抢占的"当前任务"排回队尾。
规则没错,但它没认出此刻的 rt_cur 是谁——引导期语境"就地转
正"的 idle。idle 是个伪任务,设计铁律是**不占池、不入队**,
它却顶着 RT_RUN 的态被排了进去。

## 为什么一个队列里的 idle 能炸出三种死法

入队之后,连锁反应一路向下:

- 空转时 pick 恒返回 idle,调度器把 idle 当真任务**切进去**,
  eret 进陈旧的引导帧,引导语境被当成任务重放;
- idle 的 next 指针字段与它自己的 FP 寄存器保存区重叠,队链
  写以它为笔开始野喷——队列尾指针野化后,新任务被链接到 BSS
  任意地址,rt_cur_arr、rt_ticks、壳的 sp 全部中弹;
- 被毒的帧恢复时,返回地址槽=任务指针,`ret` 一跳,跳进任
  务池数据区执行——池里的 sp 值被当指令解码,直到 PC 对齐
  错炸出 panic,或者按 SP0 向量槽路由进静默驻车;
- 主核一死,虚拟定时器停,rt_ticks 冻结,所有 sleep_ticks 永
  睡——boot 无声死。

三张脸,一条链。顺带解释了为什么它"带 gdb 就不复现":时序
敏感的窗,仪器本身会扰动它。

## 修真与残留

修复是单点:就绪队列入队处加池域硬门,池外伪任务直接拒绝。
证效立竿见影:队列毒五靴全消,boot 第一次完整走通整条开机演
示序列,零守卫开火。

案件没有全破:fork 子"被唤醒却不在队列里"的孤儿脸被守卫活
捉两次,是独立根因,发生窗在 tick 26-33;REPL 交互仍有残面。
但下一次开火,全审计会给出四类分类与双值证据——写手会被值
本身指认。

## 写在最后

这个案子最深的教训不是修复本身,而是三句话:

1. **仪器先于判据,判据先于结论**——没有守卫,你只会跟随机
   症状捉迷藏;
2. **守卫自己也要过冒烟**——首版守卫把设计常态当犯罪抓了
   2/2,是场景走查当场把它纠偏;
3. **A/B 对照是修真的牙医椅**——0/3 集中挂是回归,1/3 随机
   挂是历史病,不对照就会把两者搞反。

十四个站背着的"随机",今天卸下了一个真凶。剩下的,守卫已
就位。
