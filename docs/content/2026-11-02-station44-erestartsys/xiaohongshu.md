# 小红书卡片:站 44——系统调用的"无事发生"术 🔄

## 卡 1(钩子)

信号打断了你正在阻塞的系统调用——
调用方看到什么?
老答案:一个假错误,自己重试去。
Linux 的答案:**内核装作无事发生**。
第 44 站,把这个语义装进了我们自己的 RTOS。
#内核 #Linux #从零造系统

## 卡 2(机制)

可重启的两笔帧手术 ✍️
①elr 减 4——异常入口 ELR 指向 svc 下一条指令,
减 4=重新取指 svc;
②x0 槽不写——正常路径它是返回值槽,
重启路径保住入参,同参再入。
四行代码,一个机制。
#ARM64 #系统编程

## 卡 3(咬合)

最妙的发现:机制咬合 🔗
信号投递本来就是"整帧 272B 存档+改写"。
重启手术只要赶在存档前落笔——
handler 跑完恢复整帧,eret 自然落回拨后的 elr。
零新机器,两个旧机制咬合成一个新语义。
#架构 #机制复用

## 卡 4(判据)

判据埋在 handler 里 🕵️
让 handler 自己把 futex 字戳成 1,
重启再入的入口校验立刻 -EAGAIN。
一判决两事:
elr 没回拨→执行错窗垃圾;
x0 没保住→拿 -512 当地址野访。
判据自带反面雷,破了自动红。
#测试 #边界

## 卡 5(诚实)

哪些不重启?和重启的一样重要 📋

poll 家族 never-restart;
信号量/消息打断被 take 环吸收重挂,不生产重启。
语义表完整,不是一刀切。
