# YouTube 脚本:站 45——内核的双预算(APS+MPRT)

**时长**:约 9 分钟 | **形式**:屏幕录制 + 画外音

## 冷开场(0:00-0:50)

车规域控的本职承诺:高优先级负载保证拿到 CPU,低优先级负载
不许吃死内存。这集给我们的 RTOS 装上双预算——CPU 分区
(QNX APS 白描)+内存分区(MPRT)。参考实现 1108 行,我们
落地 200 行,因为白描的是机制不是行数。

## APS(0:50-3:30)

- 白板:guarantee+steal 两个语义;窗 20 tick 记账。
- 屏幕:apsdemo 跑——两个忙任务争跑,20% 分区实得 20%
  (数字精确对齐窗界的功劳)。
- 讲解:超标节流复用睡眠机器、偷闲判断扫描池——零新等待
  原语。
- 演示偷闲窗:对手退场后,分区任务独跑满账——"没人要的
  CPU 白给你"。

## MPRT(3:30-5:30)

- 白板:记账点=VMA 声明,mmap 与 fork 同走一喉。
- 屏幕:mprtdemo——16 页 mmap ok、再 mmap -12、孙 fork 被拒
  (窗全拷>上限)、munmap 后复 ok、退场 cur=0。
- 讲解:内存隔离连 fork 一起管;declare-time vs resident
  记账的记档差异。

## 战雷复盘(5:30-8:15)

- 讲幻影分区 0:新字段没进 create 清单,BSS 零初值=0 恰是
  合法下标——每个 fork 儿都"入组"不存在的分区 0。
- 四张症状脸一次放:子无输出/fork failed/读失败/退账 wrong
  ——一张脸各报一种错。
- 金句:野指针教你谦逊,合法下标教你怀疑一切。
- 修复三笔:字段入清单、identity 专口、fork 承继。10/10 复绿。
