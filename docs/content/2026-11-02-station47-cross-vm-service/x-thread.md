安全面在哪?不在密码学,在配置权:谁能映、映到哪、多大,只有宿主说了算。协议={seq,ack,text}:写方先备货后递增,消费方见未消费槽即读走回执——任何时刻入场皆真,不用握手。 #design

3/8
第一层坑,自家老家族第八现:新块只加了内核页表半区,忘了 per-process 半区。壳的 demo 跑在 per-proc 表+SP_EL0 语境,写窗落进"静默驻车"向量槽——不打印不 panic,-d int 才定谳。教训:stage-1 新块必双侧。 #ARM64

4/8

5/9
答案在自家调度器站 19D 的四行字里:`if (console_owner && owner != vm) continue`——console 按 VM 独占:谁持前台谁独享 CPU,后台 VM 零切片。连 vtimer 都不会注入一个没被调度的 vCPU。vm1 后台永不跑,永不见。 #architecture
