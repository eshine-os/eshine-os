# YouTube 脚本:站 47——两个虚拟机怎么说话(跨 VM 服务面)

**时长**:约 10 分钟 | **形式**:屏幕录制 + 画外音

## 冷开场(0:00-0:50)

两个虚拟机在一台 hypervisor 上,怎么安全地说上一句话?
答案朴素得惊人:一块宿主独管的共享内存+一个三字段协议。
但装它的这一站,战利品是两条用十次取证换来的纪律。

## 机制(0:50-3:00)

- 白板:PA 空档刻 2MB → stage-2 双映(vm0 IPA 0x41200000 =
  vm1 同 IPA = PA 0x52000000)。
- 协议动画:{seq, ack, text}——备货→dmb→递增;消费方见
  ack≠seq →读→回执。
- 屏幕:vm1 的 xvm 命令吃到 vm0 生产者的 ping,回执到达。

## 第一层坑:静默驻车(3:00-5:00)

- 讲义:stage-1 的两个半区(内核 PGD 与 per-process);
- -d int 日志滚动:ESR 0x25 / FAR 0x41200010 → 落点 park;
- 金句:不打印的崩溃是最贵的崩溃。

## 第二层坑:仪器全绿(5:00-7:30)

- 逐条列十连取证(别名/描述符/PC/寄存器/自写回环)——全对;
- 转折:全部正确而系统不工作;
- 揭晓:调度器四行字——console 按 VM 独占,后台 VM 零切片;
- 连 vtimer 都不会注入一个没被调度的 vCPU。

## 依律重铸(7:30-9:15)

- 白板:静默生产者(开机常驻,交换才出声)+消费者+host-owner
  窗舞(消费后交还宿主=双 VM 并跑);
- 屏幕:完整 gate 流程一次通过;
- 连带修正:apsdemo 判带随真前提放宽。

## 收尾(9:15-10:00)

- 两条纪律:stage-1 新块必双侧;仪器全绿时审规则不审仪器。
- 下集预告:批令收官站 48+统一验收。
