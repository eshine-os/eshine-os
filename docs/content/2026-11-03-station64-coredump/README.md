# 站 64:ELF core 文件(内容包口径)

## 一句话

崩溃取证落盘:野访终态在死者语境直写 aarch64 ELF64 core 文件
(ET_CORE+PT_NOTE+NT_PRSTATUS),EL0 工具与宿主独立解析双面消费——
站 46 "核文件不可为"翻案。

## 技术叙事

1. **前提翻案**:站 46 说"ramfs 只读,核文件不可为"——站 39 的
   写时复制页把"不可为"的前提拆了,站 64 只是消费翻案。
2. **死者最短路径**:crash 语境(死者本人 EL1,紧跟 exit)一次直写
   零消息往返——消息面是活任务的活路,取证面不走它。
3. **双解析器对照**:EL0 coreparse 工具+门禁宿主 python 重组解析,
   各自独立解 ET_CORE/PT_NOTE/NT_PRSTATUS——两套解析器同一文件
   出同一语义,binfmt 形才算真。

## 金句

- 消息面是活任务的活路,取证面是死者最短路径。
- 一个格式算标准,当且仅当两个互不相识的解析器读出同一语义。
