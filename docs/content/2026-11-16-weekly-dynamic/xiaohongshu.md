## 正文

开源公开完成 ✅ 这周的主线：GitHub 主仓 + Gitee 镜像 + 官网三件套上线。

但你们猜这周我写了多少行内核代码？**零。**

整周都花在把"能跑的私仓"变成"敢让人看的公仓"，五件事全是发布工程：

🧹 **合规清洗**：两百多个提交的全历史过堂，内部引用全部中性化，改完复扫到 CLEAN——git 历史里不能藏私货
✍️ **真实署名**：AI 结对不装人。`Model:` / `Assisted-by:` 写进 trailer，validator + git hook 机器背书，历史模板在文档里坦白
🏠 **环境隔离**：单工作根 + 宿主无关检查，克隆下来 make 就能跑
📦 **容器化**：`--network none` 的容器里从构建到 QEMU 开机到交互 shell——没网还能跑，才是真没隐式依赖
🪞 **诚实边界**：KNOWN-ISSUES 挂门口，没修完的五条缺陷白纸黑字（双核污染族、shell 空格洪水、两连真绿未达……）

发布第一天还收到个报告：官网在手机上 mainline 表格超屏了 70px 😅
根因是移植 kernel.org 主题时漏了一条媒体查询规则（人家手机端靠它让表格滚动）
补回上游规则、CSS 升 v7 穿缓存，DOM 探针 + 逐字节截图验证——已修 ✅

现在的状态：68 个开发站、183 个验证门、自研约 2.5 万行 C/汇编，Apache-2.0。
下周计划（缺陷预算优先，有 P0 不开新站）：
1️⃣ 双核污染族 root-b/root-c 攻坚
2️⃣ 183 门两连真绿
3️⃣ shell 空格洪水自首
之后才开站 69（EL2 边界 fuzz / 亚 tick 定时器 / 真板预习）

GitHub 搜 eshine-os，官网 www.eshine-os.org，Gitee 也有镜像～
每周一更周记，看着一个人 + AI 能不能从零长出一个 OS 底座 🌱

你们开源前最花时间的是哪一步？评论区聊聊 👇
