## 正文

**11/14，eshine-os 正式开源了。** 从这周起，每周一发一份周报：
上周改了什么、这周做什么、哪里可以来参与。

先说人话：这是一台机器当好几台用的底层系统——自己写的「总管」
（hypervisor）+ 自己写的实时小系统 + 一块真正的 Linux，同时跑在一台机器上。
代码是我和 AI 结对从零写的，68 个开发站、183 项自动检查、约 2.4 万行自研代码。

**这两周没写新功能，全在修问题（都跟"手感"有关）：**

⌨️ **命令行不卡了**
· Ctrl-D 终于能结束输入，cat/wc 不再卡死终端
· `ls`、`cat ./xxx` 这类相对路径能用了
· 偶发开机卡死的真凶找到了：两个执行流互等一把锁，藏了两周多，修完连开 6 次全绿

💥 **崩溃变人话**
没装 Linux 内核就启动虚拟机，以前跳空内存报神秘地址；现在直接说
"Linux Image not loaded"——缺啥补啥，一步到位

🚀 **一条命令跑起来**
· `make run` 缺依赖自动下载补齐
· README 加了 Docker 一条命令跑法，容器里也能交互敲命令
· 克隆即构建：不再写死"某台电脑的路径"

🧹 **发布工程**
· 两百多个提交的全历史过堂清洗，复扫到 CLEAN
· AI 署名不装人：Model / Assisted-by 真实记录，机器把关
· KNOWN-ISSUES 白纸黑字挂 5 条没修完的缺陷

🌐 **官网 + 架构图**
架构图按功能安全（ASIL）和信息安全（CAL）双轴分级；发布第一天收到手机端
表格溢出 70px 的反馈，当天修好、像素级验证 ✅

**这周（26.11-3w）计划：**
1️⃣ 双核偶发问题最后两层攻坚（[37]/[38] 两项检查目前稳定失败）
2️⃣ 183 项检查连跑两遍全绿
3️⃣ shell 空格洪水问题自首
4️⃣ 之后才开新站 69：EL2 安全边界 fuzz / 亚 tick 定时器 / 真板预习

**想一起抠细节的工程师欢迎来：**
内核 / 虚拟化 / C 汇编 / 嵌入式 / 测试 / 文档 / 前端，都缺人。
最低门槛：克隆 → `make run`（或 Docker）跑起来 → 翻 KNOWN-ISSUES 认领一条 →
提 Issue 说你想做哪条。

GitHub 搜 eshine-os，官网 www.eshine-os.org，Gitee 有国内镜像。
每周一见 🌱
