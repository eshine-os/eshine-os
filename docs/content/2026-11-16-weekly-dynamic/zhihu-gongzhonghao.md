# 11/14 开源之后，第一份周报：一个人 + AI 造的 OS，这两周改了什么

> eshine-os 开源周报 第 1 期（周标签 `26.11-3w`）。
> 从 11/14 仓库正式开源起，以后每周一发一份周报：上周做了什么、本周做什么、仓库怎么参与。

## 三句话说明它是啥（给第一次听说的人）

- 它是一种**「一台机器当好几台用」的底层软件**（术语叫 Type-1 hypervisor，虚拟化底座），
  直接管硬件，底下不需要 Windows 或 Linux 当宿主。
- 机器上同时跑三块：一块**自研的实时系统**（反应快、专门管安全）、
  一块**真正的 Linux**（跑智能驾驶应用）、一块预留座舱域。
- 代码是**一个人和 AI 结对、从零写出来的**，Apache-2.0 开源，每一段开发都有可重放的自动检查。

当前数字（截至发稿）：**68 个开发站、183 项自动检查、240+ 个公开提交、
自研约 2.4 万行 C/汇编**。主仓在 GitHub，国内镜像在 Gitee，官网 www.eshine-os.org。

## 这两周做了什么（26.11-2w → 26.11-3w）

先给结论：**没有开新功能站，全部在修问题、补体验、做发布工程。**
按"普通用户能感知"的顺序排：

### 1. 命令行不再"卡死"

- **Ctrl-D 能真正结束输入了**。以前在自研 shell 里跑 `cat`、`wc` 这类
  "一直读到结尾才停"的命令，按 Ctrl-D 也停不下来，终端就卡在那儿；
  现在按下就干净退出。
- **相对路径能用了**。`ls`、`cat ./etc/motd` 这类写法以前会报"找不到"，
  现在工作正常——这是日常使用频率最高的一类小问题。
- **偶发开机卡死，真凶找到并修了**。这是一个藏了两周多的"锁竞争"：
  两个执行流在特定时序下互相等对方的锁，整个机器跟着卡住。它只在
  特定负载下现形，难复现；修完后静置连开 6 次，全绿。

### 2. 出错时说得明白，不再神秘崩溃

以前没装载 Linux 内核就启动第二台虚拟机，程序会跳进一段空内存，
报一个看不懂的地址错误。现在会直接告诉你：**"Linux Image not loaded"**
——缺什么、怎么办，一步到位。

### 3. 一条命令跑起来

- `make run` 发现缺依赖会**自动下载、自动补齐**，不再要求你先手动
  准备一堆外部材料。
- README 新增 **Docker 跑法**：钉版工具链容器里，构建、启动、敲命令
  一条龙；容器里也能真正交互（能看也能敲）。
- **克隆即构建**：所有构建产物收进一个工作根，仓库里不再写死"某台电脑
  的路径"；配套的检查脚本会扫出宿主路径泄漏。别人克隆下来 `make` 就能跑。

### 4. 发布工程（看不见，但决定仓库敢不敢让人看）

- **历史清洗**：两百多个提交的全历史过了一遍，内部引用全部中性化，
  改完复扫到 CLEAN——git 历史里不能藏私货。
- **AI 署名不装人**：提交信息里用真实语义记录 `Model:`（主模型）、
  `Assisted-by:`（实际参与的模型），validator + git hook 机器把关；
  历史里的旧式模板在专门文档里坦白说明。
- **诚实边界**：KNOWN-ISSUES.md 挂在门口，5 条没修完的缺陷白纸黑字。

### 5. 官网与架构图

架构图按 **ISO 26262 功能安全（ASIL）** 与 **ISO/SAE 21434 信息安全（CAL）**
双轴分级，一眼看出那些部件是安全关键、哪些是信息安全关键。
发布后第一天就收到一个手机端报告：发布表溢出屏幕 70px——根因是移植
kernel.org 开源主题时漏了一条媒体查询规则，当天补回、缓存穿透、像素级验证。

## 本周（26.11-3w）要开发的内容

这个项目有条铁律：**有已知的高优先级缺陷时，不开新功能站。** 所以本周：

1. **多核并发偶发问题的 root-b / root-c 攻坚**：双核 demo 的两项检查
   [37]/[38] 目前是稳定失败（2/2），根因家族还剩两层没剥完，守卫和
   取证工具已经武装到位；
2. 收敛后，**183 项检查连跑两遍全绿**（要等一个安静的窗口）；
3. 自研 shell 的**空格洪水问题自首**（快速输入大量空格时偶发异常，
   约 1/3 概率，绊线已埋）；
4. 以上清账后，才开**站 69 候选**：EL2 安全边界模糊测试 /
   亚 tick 定时器 / 真实硬件外设隔离（SMMU·GIC-ITS）预习。

## 为什么要每周发一次

因为**开源不是发完就完了，是让仓库活起来**。周报三件事：
本周改了什么、下周改什么、哪些缺陷欢迎来认领。
每周一打周标签（本周是 `26.11-3w`）+ 发周报，节奏固定，长期可见。

这个项目缺的不是想法，是**能一起抠细节的人**。欢迎这几类：

- **内核 / 虚拟化**：EL2、vGIC、stage-2 地址空间、SMMU；
- **C / 汇编 / 嵌入式**：RTOS 调度、驱动、真实硬件 bring-up；
- **测试 / 工具链**：把 183 项检查磨到两连真绿、写新的判据；
