# 一个竞态,让整个系统假装活着 😶

给 RTOS 加日志持久化(站 50)。功能写完,冒烟四连绿,然后突然:
busybox cat 任何文件——命令回显了,输出没了,退出码也没了。
系统"活着",但什么都不说。

尸检三层:
🔍 第一层:cat 没输出也没退出
🔍 第二层:开机链一行 "pm stdio bind failed"——shell 的 stdio
   没绑上,cat 把内容写进了自己刚打开的文件 fd
🔍 第三层:新加的日志服务在 boot 期发起十几个阻塞往返,和 PM
   的 200ms 绑定窗同拍,打散了 FIFO 序——间歇五五开

修法不是加宽重试(那是遮),是撤走竞争源:日志服务的文件操作
全部惰性化,开机窗口谁都不跟 PM 抢。修完 4/4 稳 ✅

教训:竞态最爱藏在开机那 200 毫秒,所有服务同时抢跑的地方 🏁
