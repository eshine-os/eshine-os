# 站 50:slog 持久化+procfs(内容包口径)

## 一句话

日志从"环里看一眼就没了"变成"写进文件、轮转保史、随时 cat 回读"——
外加 /proc 三个真文件:内存账、CPU 表、中断计数。

## 技术叙事

1. **服务器互为客户端**:slogsrv 要写文件,不走内核捷径,而是像任何
   用户进程一样走 open/write 消息面——微内核的正道,零 API 泄漏。
2. **双世代轮转**:写满 3.5KB 就换文件名(slog/slog.1 交替),unlink
   一侧+create 一侧,零拷贝完成轮转——8MB 内存预算下的诚实形。
3. **klog 双源**:内核日志环增量收割入卷,'S ' 前缀的用户日志同卷
   共存——一份数据,两个来源,同一个文件。
4. **深径路由**:openat("/proc/meminfo") 第一次真正路由到 procfs
   ——最长前缀匹配,名字空间的补角。

## 金句

- 日志不落盘,等于没发生。
- 让服务器当客户端,是微内核给架构上的第一课。
- 竞态最会藏的地方:开机那 200 毫秒。

## 数字

- 门禁 139→145;冒烟 19/19×4;字节环收割游标模型 phys(K)=K%SIZE;
- 轮转阈值 3.5KB(4KB 页上限的诚实余量)。
