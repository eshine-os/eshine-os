口径(README 索引):
- **A irq 注册表**:四硬编码 INTID 分支(27/0/33/35)退役,替换
  式登记+链式包装(RT_RX_BIT 泛化为登记方携带的掩码);irqdemo
  换 33 号槽计数/恢复——设计盲点两连实测(换钩在命令字节消费
  之后、计数供给=探针 x 而非命令字节)皆入判据修真,demo 自
  同步等探针(5 tick 一探预算 2s,手动走查也成)。
- **B 水位守卫**:live-sp 判(区别站二十一历史高水位)——危险线
  384(ISR 链写进 magic=下一拍哨兵 panic)、告警线 640;**实测
  修真:守卫读的是 ISR 链读点下方 sp,两线分属两坐标系(评审
  disassembly 钉账:守卫链 272+48+64=384 恰危险线,初版停点仅
  +48B 余量=量化运气)**;lowdemo 重锚后贴线深旋恰一次 warn
  (本 build 打印 400)、magic 不误伤。
- **C 延迟冲刷**([54] 残余收编):泊位武装 CNTPCT+20ms、泵入口
  扫描+**fire 时刻复验同一静默判**(陈旧武装不拦腰冲行——评审
  抓出的 [54] 双雷复发面)——**零宿主时钟手术**(站二十二"需
  100Hz 宿主钟"的定性被绕开);时间基=CPU0 宿主壳忙自旋(µs 级
  恒在,评审纠偏:不是 vm0 tick);echo 风暴门 10/10(延迟化前
  23/60 撕→探针 0 撕)——评审迁窗:初版门位 owner=host 恒绿
  空转,终落真并行窗(vm2 靴流内 vm1 前台)。
- **门禁 76→79**;门侧假红三连修真(R-a [38] fpsmp 读序竞态、
  R-b [43] irqdemo x 时序、R-c/d [47] token 分块缝>20ms 延迟
