# 站 67:根目录枚举修真(内容包口径)

## 一句话

用户报障 `ls /` ENOENT——站 40 目录前缀柄的四处"直接子项"判定
全以 b[dl]=='/' 作深判锚,根前缀 dl==1 使判定恒假。

## 技术叙事

1. 定谳链:ENOENT(根柄判死)→截名("/tc"=etc 丢 e,名起点 +1 越过
   名首字)→去重失效(etc×4/bin×10)——三个症状一个根:根特例缺。
2. 修真:rf_under 根恒真+深判豁免+名起点 `dl==1?1:dl+1` 四处特判。
3. DT_DIR 深径探测以完整路径作前缀,根下语义本来正确,不动。

## 金句

- 目录逻辑的特例名单里,根目录永远排第一——它是最常见的边界。

## 数字

- 四处特判;ls / → tmp/etc/bin 各一次;场景 21/21;[183] 扩根枚举。
