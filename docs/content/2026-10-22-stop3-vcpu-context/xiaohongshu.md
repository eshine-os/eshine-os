# 小红书:坏 guest 杀不死我的 hypervisor 了

## 正文(文案)

今晚的自研 hypervisor 三连达成💪

1️⃣ 陷阱帧:guest 的 x0-x30+栈指针+PC 全量进帧
→ EL2 从此随便用寄存器,不再靠"编译器恰好不碰"

2️⃣ yield 断点续跑:
guest 主动让出 → 宿主随便干活 → 再进 →
**guest 从断点原地复活,像函数返回一样自然**
(画进状态机一整周的 PAUSED 状态,今天第一次真被用上!)

3️⃣ 坏 guest 杀不死宿主:
guest 读野指针 → VM 干净死 + 打出诊断
**诊断里能看到野指针的原值**(帧的意义)
宿主 shell 继续打字,毫发无伤🛡

最肥的坑:每处理一次 HVC,异常栈净漏 110B——
第 79 发陷阱碾穿栈底,踩爆指针
上一站没炸,纯粹是余量还没用完🫠
修法一句话:异常入口把栈归位,别指望出口

还有 GCC 把我的测试判据常量折叠没了这种事…
一行空 asm 救回来

每天 1-2 小时 AI 结对,27.04 连载第 3 篇
代码全开源 Apache-2.0,门禁 17 步连过💚
