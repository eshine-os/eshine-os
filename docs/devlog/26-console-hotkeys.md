# 站二十六 devlog:控制台快捷键(Ctrl-^ 前缀,vm0/vm1/vm2 直切)

> 承接站二十五(e7b8ab3,79 门双绿)。用户令:"通过快捷键来切换
> vm0,vm1,vm2 的 shell 吧。你看看用哪个快捷键比较好,然后在
> 代码中实现它。" 单块小站,门禁 **79→80**,终树双绿。

## 0. 选型(键面是稀缺资源,选型即排雷)

- **不可动**:0x1d(Ctrl-])=站十五逃生夺回(Xen/ssh 惯例),三站
  门禁与全部探针锚定它——改语义即破 [73] 逃生契约。
- **不可偷**:Ctrl-A..Z 大多有宿主/guest 语义(0x03=SIGINT 归
  Linux tty、0x04=EOF、0x1c=SIGQUIT、0x1a=SIGTSTP……偷任何一个
  都破 guest shell 真实性);F1-F3/方向键=多字节转义序列,裸
  串口下与 vi/bash 的 ESC 用法无法无歧义区分。
- **定案 Ctrl-^(0x1e) 前缀**:①与 0x1d **字节相邻**——"Ctrl-]
  夺回宿主,Ctrl-^ 跨 VM 直切"一对心智模型;②**无 TTY 信号
  绑定**(RS 记录分隔符,Linux tty/readline/vi 全不用;vm0 RTOS
  壳 0x20-0x7e 过滤器零成本);③前缀键有 QEMU Ctrl-A/tmux/
  screen 先例,双键前缀不与任何单键输入争用。
- **语义契约(QEMU Ctrl-A 同律)**:`Ctrl-^ 0|1|2` 切 vm,
  `Ctrl-^ h` 回宿主,`Ctrl-^ Ctrl-^` 双击=字面 0x1e 直递当前
  owner;**未绑定键=前缀取消、本键照常处理(不吞字节)**;
  0x1d 逃生优先级恒高(前缀态随夺回清零)。

## 1. 实现(最小面,零行为差异)

- vmconsole 命令体原样提出为 `console_to_host()/console_to_vm(id)`
  公共函数——**快捷键与命令字共用同一函数**:状态门拒绝(被拒不
  夺台)/owner 落位/唤醒/切换消息/站 20 冲刷次序全同。
- shell_run 输入层单字节前缀态机(`vmkey_pending`):pending 时
  绑定键走切换,其余一律清 pending 后 **fall-through 本键照常
  处理**——双击字面因此零复制(落入下方站 24 推环唤醒不变量
  全路径:push+dmb+ws 唤醒+ev9+poke),取消路径因此零损坏;
  无 goto 无重复代码。
- **两条路径统一**:owner=guest(会话中直切他 VM)与
  owner=host(宿主快捷进入)同机工作。

## 3. 巡壳冻屏追查与提示符修真(站后补丁,用户实测报告驱动)

- 用户交互实测报"快捷键切换正常,但最后界面卡住"。三重复现世界
  全绿:**socket chardev 全巡零延迟**(vm0 hb/vm1 selftest/宿主
  tick 全 0.00-0.01s,逐字符零泵延迟)+**PTY 复刻 -nographic 世界
  全巡 0.2s 级**(含静默 3s/8s 后交互不冻)+**XOFF 排除**(注入
  0x13 后输出照流——QEMU stdio 置 raw 已弃 IXON,Ctrl-S 冻屏
  不成立)——**树无冻结**。
- **真修(观感主因之一)**:逃生 0x1d 与快捷键 h 两路回宿主后
  **不印提示符**(命令路径的 eshine> 由 dispatch 流程补,两路
  均绕过)——静止无提示符的屏无法判活,正是"卡住"观感的组成;
  教学表也明诺"回宿主 eshine>"。修=两路各补 console_puts
  ("eshine> ")(勿入公共函数免命令路径双印;verify 六处 eshine>
  锚逐一核对不落逃生窗后,零判据风险);冒烟两路锚
  "console -> host(escape)\r\neshine> " 全过;双绿复挣。
- 终端侧嫌疑判档(非树病,用户自验):①**Ctrl+Shift 是中文输入法
  切换热键**——每次热键若带 Shift 即有翻转 IME 之险,IME 落中文
  态后敲字进候选窗不达串口=冻屏观感(首选规避=**用 Ctrl+6 不带
  Shift**,同为 0x1e);②终端滚动回看态新输出不滚屏=静止观感;
  ③VSCode 键位截获。均非本树可达面,记档。

## 4. 残余(诚实边界)

- 字面直通(双击)不设门:三客壳过滤器均吞 0x1e,判据不可见
  (功能在、见证缺,靠 spec/help 文档);
- 前缀态无超时窗(裸串口下无时序歧义):pending 悬置至下一键,
  跨切换残留即下一键自然解决;
- vm1 的 `vm1>` 提示符不随切换重印(壳静止于旧提示符,输入即
  回显)——vmconsole 时代同貌,非快捷键新面。
