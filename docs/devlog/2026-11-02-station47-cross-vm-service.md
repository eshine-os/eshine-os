# 站四十七:跨 VM 服务面(safeshm 窗+vm0 设备后端)

**日期**:2026-11-02
**状态**:实现完成,冒烟 13/13;门禁 132(新 [127])按批令写而不跑
**spec**:docs/specs/2026-11-02-station47-cross-vm-service.md

## 机制

- **safeshm 窗**:宿主自有 2MB 物理雕刻(PA 0x52000000,三客 RAM
  之外的空档)经 stage-2 双映 vm0/vm1(IPA 0x41200000,块 9,
  mem[1] 槽零新机器);配置权唯一属宿主=安全面所在。协议=
  {seq,ack,text[64]} 代际槽位:写方先 text 后 dmb 再 bump;
  消费=见 ack≠seq 读 text 后 ack=seq——任何时刻入场皆真。
  **零拷**(参考实现 VM_SET 单拷的优记档)。
- **vm0 设备后端形**:窗在 RTOS stage-1 入内核 EL1-only(块 9,
  UXN+PXN),EL0 经内核代访=设备驱动同律;vm1 侧裸机直访。

## 战雷连环(本站最大战果=前台独占泵律定谳)

1. **SP0 静默驻车(站 28 家族)**:首版只在内核 PGD 加块 9——壳
   demo op 跑在 per-proc 表+SPSel=0 语境,写窗落**SP0 同步槽=
   guest_park 静默驻车**(不打印不 panic,-d int 定谳:ESR 0x25/
   FAR 0x41200010→0x40013000→park WFI 循环)。修=per-proc L1
   半区同补块 9。**教训:stage-1 新块必双侧。**
2. **十连仪器取证空转**:交换不通后,gdb 逐项证明:窗别名(seq=1
   在 PA)/双侧 stage-2 描述符同值(0x520004fd)/vcpu 存档 PC 恰
   在轮询指令/x5=0x41200000/x6=0/自写回环活——**每一项都正确,
   答案却在调度器**:
   **站19D 前台独占泵律**——`if (console_owner && owner≠vm)
   continue`:谁持前台谁独享 CPU0,后台 VM 零切片(vtimer 也不
   注入未调度的 vcpu)。vm0 持前台写窗,vm1 后台永不跑=永不见。
3. **依律重铸 demo**:开机常驻 **xvmsrv 生产者**(静默,真交换才
   出声=站 24 安静承诺;槽位占用即候,未消费恒挂不重发)+vm1 客
   **xvm 消费者**+**host-owner 窗舞**(xvm 消费后 `host` 交还
   RX=owner NULL=双 VM 并跑)——热键 \x1e1 入 vm1(宿主命令在
   owner=vm0 时不可入)。
4. **apsdemo 偷闲判带随律放宽**(40→20):常驻 xvmsrv 周期性就绪
   ="独跑"前提成真竞争,25/45=机制活证(无竞争对照 ~8)。
