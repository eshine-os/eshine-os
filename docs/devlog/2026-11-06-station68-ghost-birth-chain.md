## 1. 出生链定谳(五步全息)

向量表 [vec.S:21-40] 的**槽位即语境铁证**:

1. EL0 任务陷入异常(SVC/IRQ)→ `RT_EL0_ENTER` 渡 **SPSel=0**:
   内核处理语境=EL1 用 SP_EL0 库当活栈(=任务内核 C 栈),
   SP_EL1 库驻蹦床顶(32B/核,为下次 EL0 异常的 scratch 仓)。
2. SVC 处理边界 `daifclr`(站28 契约,阻塞调用需要)→ **C 处
   理中开中断**。
3. tick 落在 C 处理中(引导期 fork 的 as_copy、shell read 的
   搬运环,皆此窗):异常取自"EL1+SPSel=0"→ 硬件选 **"Current
   EL, SP_EL0" 槽**(旧表直通 guest_irq),入场强制 SPSel=1
   → `RT_PUSH_GPRS` 把 **272B 帧压上 SP_EL1=32B 蹦床**,踩
   蹦床邻域;psr 存照=EL1t ✓ 全捕获吻合。
4. 若 tick 决意切任务:簿记 `old->sp = sp` = **蹦床域地址**——
   毒 sp 注入完成;任务真帧(在 SP_EL0 库上)成孤儿。68C-3 臂
   点域检后来拦截的就是这枚已毒值。
5. 复活:`.Lel1` 从蹦床残值弹"帧"→ eret 携 psr=EL1t → **SPSel=0
   而活栈=SP_EL0 库=他人残留**(实测=别任务 usp)→ 幽灵以用户
   栈跑内核 C;下个 tick 又取 SP_EL0 槽又压蹦床 → **自复制**;
   蹦床地址确定性 → **跨靴同值**。站 32"打出的恰是别家函数字
   面"、站 68 复合帧解剖(psr=EL1t+调度器头+用户尾)全部下游
   同根——站28 日生的潜伏缺陷,单核时代窄窗,站 20 SMP+站 35
   EL0 负载后成必踩。

## 2. 修真(站68F 两件套,配对成环)

**B1 改道**(vec.S 向量槽 23 → `guest_irq_sp0`):"Current EL,
SP_EL0" 槽 IRQ 先渡回 SP_EL0 库(=被中断任务自己的内核 C 栈)
再压帧——帧满嵌套任务栈域,簿记存值在域,门检恒绿;同任务
返程弹栈推进即自然回位。渡口一步无窗(异常入场 DAIF 全掩)。

**B2 库还**(`.Lel1` 站68F 分支):目标 psr=EL1t 的复活,帧顶
(GPR 块基+256,恰=压帧前活 sp,续跑 ABI 栈自然回位)必预还
SP_EL0 库——弹栈在 SP_EL1 库推进,SP_EL0 仍驻他人残留就是幽灵
第二脸。两语境(SPSel=1 常路经渡口对岸写/SPSel=0 换库路直写)
同律覆盖;EL1h 目标(coop 帧/EL1h 抢占)零改动原路。

## 5. 教训(仪器战争结案陈词)

1. **守卫即战果**:无 68C 域检,这是又一个"偶发玄学挂"躺着
   过站;有守卫,出生点三小时内指认。为可疑不变量装门口哨兵
   是值得的常驻税。
2. **"悖论"先查取景框**:psr(存照)与 spsel(现值)本就分属
   两语境,对着同一帧各说各话不构成矛盾——被"mixed state"
   假说带偏一轮,68C-18(EL2 pstate-银行一致性)实为伪仪器,
   未建即被向量槽分析替代,是本站最划算的一次未做。
3. **槽位即语境**:ARM 向量表 16 槽是"从哪来+当时用什么栈"的
   完整谓词,EL1 双库设计里"Current EL, SP_EL0" 槽是必须专门
   接的第四种入口——站 28 只接了两种(EL0 入/EL1h 入)。
4. **帧手术完整性清单再+1**:凡改活栈必清点两库(t->sp 契约
   只存了活跃库值,另一库是被 272B 帧遗漏的第 33 个寄存器)。
5. **一致性≠正确性**(68C-13 教训续):臂点复核全绿只因臂值
   源头全错得一致。
