    本证明与彼判一致,五站绕了一圈的锚点终于钉死。

    线;进出两窗 DAIF 同屏(站十六封的 25% 窗)。

## 2. C 块:泵扫级 vtimer 兜底(真实可达的延迟类)

- **可达类**:泊定 TIMER 帧的唤醒只押 26/27 IRQ 驱动的 sweep
  ——**介入运行者**(他 VM 的片)进场装回自己的 ctx 即覆写
  本核物理线,泊者挂起的 27 蒸发,唤醒迟至 1Hz 26 扫描
  =**tick 迟到 ≤1s**(µs 应得)。CPU0 轮转世界 vm1 片(1s 量子)
  内 vm0 泊定到期即此;vm2 双核深睡同理。
- **修**:泵扫 ws==1 复查网 vtimer 臂——`reason==TIMER && ctl&1
  && cval<=now` → ws=2(WOKE 专属注入块照走,guest 认账重装
  闭环);**时钟读后置**(mrs 只对 armed TIMER 泊帧付账,收尾
  修真:旧位每圈无条件读在四核自旋泵下烧成 TCG 热耗面)。
  探针:vm1 后台 spin+vm0 前台 hb×6——tick 708→2720,每 4s
  恰 ~400=100Hz 均匀无顿挫;六发全回复。
- **评审修真:热活锁上界**——consume-fail 帧同 cval 连醒 2000
  次即停醒+**CARM-STALL** 一行标记(整行持锁),cval 变即清零。
- pending⇒runnable 至此在全部四类可交付事件(vtimer 过期/
  owner RX/virtio 完成/搁浅 SGI)上泵扫级成立。
