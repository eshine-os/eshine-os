## A 块:[54] 闪断家族定谳(三案:站18 1/8、站19 1/12、站21 R1b)

### 取证:needle 不是缺席,是字节级互撕

R1b 的 TimeoutError 自带全量 `output so far`——重读这份被 tail -12
掩埋的证据,发现 `spinning...` 根本不缺,是被撕成了:

```
vm1> spin
spinni[vm2] [   n 0.1339g17] CPU feature
```

vm1 的 "spinni|n|g..." 与 vm2 的 `[    0.133917]` **互相嵌进对方
字符串中间**(vm2 时间戳里嵌着 vm1 的 n 和 g)。read_until 找连续
needle → 永不匹配 → 假阴性超时,客机全程健康。三案同签名全部
解释。

### 根因两层(读代码锁图定位)

1. **`console_putc` 原语不持锁**:`console_puts` 持锁,putc 裸奔
   ——vuart fg 逐字符透传(站六形态,18D 与 [41] 两轮加锁都漏了
   它)是唯一高频裸写者:cpu0 上 vm1 每字符一陷阱一裸写,cpu1/2
   上 vm2 的锁内整行 emit 拦不住锁外写,两流字节级互撕。宿主
   shell 回显/vmrx dump 同类裸写者一并盘点在案。
2. **fg 逐字符透传的字符缝隙**:即使每字符原子,字符间缝隙
   (MMIO 陷阱出口/泵边界)可被整行 vm2 输出嵌入——needle 仍碎,
   概率降不归零。

### 失败测试先行(probe-tear)

echo 风暴探针:vm2 靴流窗内打 60 发 needle 行(放大 ~100×)。
修复前:4+ 撕(含 `[  n  g0.000000]` 双向字节撕裂实锤)。

### 修复三层(每层实测反转验证)

1. **原语持锁**:console_putc 按 owner 递归持锁(全类一次治)。
2. **fg 行缓冲化**:fg 字符入 tx 缓冲(bg 同律,tag 对称),
   `'\n'` 经 vuart_tx_emit 锁内整行原子——**输出行 0/60 碎**。
3. **泊位冲刷**:客 WFI 停泊且 RX 环空才冲半行(键回显即时性,
   人类敲键尺度无感);**爆发感知**(RX 环有字节=chardev 分块缝,
   跳过冲刷免拆回显)。

### 第二雷:自己的门禁抓自己

A 轮 R-a 在 [74] 复活链炸出新撕裂:`[vm0] rtos> c[vm0] pu1: online`

泊位冲刷恰落在 vcpu1(cpu3 泵)在途追加的 "cpu1: online" 行中间,

### 残余(机制清晰,记档)
