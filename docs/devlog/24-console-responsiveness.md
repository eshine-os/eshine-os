## 0. 诊断战记(②的真根因,系统调试纪律全程)

- **判负实验先行入档**:首发假设=进场全量 tlbi 风暴论(vcpu.c:69
  幸存者,站十九只门了 vttbr 侧那发)——-d int 实测判负:fp 窗
  异常率 606/s=RTOS tick 三连([EL2 IRQ]+[Virtual IRQ]+[WFI 陷阱])
  ×100Hz×双帧的**预期音量**,非风暴;E4 echo 900 字符(~1800 MMIO
  陷阱,内联不过 vcpu_run)0.00s 反证陷阱路径零 flush 税;修后探针
  无改善。**修保留**(站十九不变量自洽),收益记"无实测增量"。
- **翻案一**:全数"慢命令"数字(cat cpuinfo 40s×2/fp 90s×2/
  busybox 循环 60s)细看全是 read_until **超时假象**——-d int 的
  90s"fp 窗"内 guest 全程 idle 打拍,fp 任务从未跑:命令字节入
  环后无人醒。
- **定谳**(多探针+forensics):健康路径全快——逐字符回显 24/24
  字符 0ms、900 字符 echo 0.00s、**fp 0.04s**(输入即达轮)、
  `vmtrail` 泊→醒 33µs(ev12 now−ev1 cval 实算)。**"卡顿"=输入
  蒸发**=[41] 家族脸 #5 满强度:0ms 或 30s+ 两态,无中间态。
- **取证工具课**:`vmtrail` 是裸命令(exact-match,带参会
  unknown);trail 解码表——ev1 泊位(reason,cval)/ev5 存档
  (ctl,cval)/ev12 扫描(now)/ev2 WOKE((id<<4|vi),now)/ev3 泵入
  ——**cval/now 皆 CNTV 绝对值,唤醒延迟可直接配对实算**;
  **forensics 的 Heisenberg**:vmstat/vmtrail 命令本身=原子段,
  dump 期间泵停摆,尾窗 ev2-无-ev3 是测量伪影勿归因产品。

## B 块:输入⇒runnable 不变量(用户令②根因)

- 两洞(检查面+实测双定谳):①推环直通唤醒只认
  `wait_reason==VCPU_WAIT_RX`,而泊位分类按 vtimer_ctl&1 归
  TIMER——**真 Linux 恒 armed 恒 TIMER**(trail ev1 a=1 实证),
  旧门下输入只能等客自家 vtimer(vm0 ≤10ms 尚可,vm2 深睡=秒级
  ~永不);②推环唤醒与停泊出口窗竞态(读 wait_state=0 不醒→
  随后泊定→环内字节无主)。
- 修:推环侧唤醒去 reason 门(`wait_state==1` 即翻 runnable,
  WFI "pending 即醒"语义补全);泊位侧落定复查(**评审三修**:
  (a) Dekker `dmb ish` 对偶双侧——环写/wait_state 写皆普通存取,
  无障下双侧读旧值同拍丢唤醒,锁内 release 只序先前访存勿倚;
  (b) 复查过泵入口同门(vuart_rx_irq_ready+vgic 使能)防
  无 RXIM 客的泊-醒热自旋;(c) 事件码 ev16 专用勿复用 ev1
  ——站二十 [41] 探针契约保护)。
- **不变量语义**:console 输入路径与 vtimer 健康度解耦——[41]
  家族 vtimer 侧真凶(五站五脸)仍可致静默停摆(心跳断流),
  但交互永不再蒸发;vtimer 根因留专站。
- 探针:vm0 深闲置 5s 后 ps **0.00s**;vm2 深闲置后 echo
  **0.00s**;**大 dump 后泊位+立即输入 0.00s**(=R-f [76] 30s
  脸直接对照,用户"非常卡顿"病根闭环)。
