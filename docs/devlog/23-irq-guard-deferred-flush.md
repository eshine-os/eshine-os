## A 块:irq handler 注册表

- 四硬编码分支(27/0/33/35)退役:`rt_irq_register(intid, isr,
  wake_mask)` 替换式登记(返回旧 isr 供链式包装);IAR→查表→
  **isr 先行,掩码后醒**——RT_RX_BIT 由 uart 登记携带,"按掩码
  唤醒"泛化完成;无登记 intid 一行报(默认拒绝面诚实化,同源
  静默抑制——评审:持续未知源防 ISR 语境行级洪泛)。
- 工程面:INTID 常量留 gic.h 合法 TU(单含静态头拖进 rt_demo.c
  会产未用静态警)——demo 经 `rt_irq_swap_uart` 助手换/恢复
  33 号槽;先建任务后换钩(池满不污染登记面,评审抓出)。
- **irqdemo 设计盲点两连**(探针实测):换钩发生在命令字节消费
  **之后**——命令自身的 IRQ 不经过 wrap(首版"chained 0"假阴
  性,首版机理叙述为假);补发 x 同拍爆发整批被换钩前 ISR 消费。
  定谳:计数供给=探针 x,demo **自同步**等探针(5 tick 一探,
  预算 2s,超时诚实保底)——门判 0.1s 补发、手动走查、迟探皆成
  (评审:固定 30 tick 窗对手速过苛)。判据:N>=1 + 恢复后
  `ps: task table`(原 drain+RX 唤醒语义无损)。

## B 块:水位守卫(live-sp 判)

- 站二十一的水位是**历史高水位**;守卫量**此刻**:tick 异常帧+
  扫描/回调链(RT_ISR_BUDGET=384)落点低于可用底即写进 magic
  区,下一拍哨兵必 panic(危险线);告警线 RT_GUARD_LINE=640,
  低于一次性 warn(low_warned 旗,create 清零;deepdiver 封窗深
  潜 tick 看不见,零假阳性;lim==NULL 的 idle 语境免判)。
- **实测修真(探针)**:守卫读到的 sp 是 **ISR 链读点下方**的
  值——tick 守卫自身跑在被打断任务的栈上,读值≈真 sp−350。
- **评审 disassembly 二锤**:守卫链=272 异常帧+48 dispatch+64
  bookkeep=**384 恰危险线**;初版停点 lim+600 实测**仅 +48B 余量**
  ——量化运气过线(帧 64B/级,站21 的 96B/级推断错一级),帧步
  一变即砸哨兵守卫变 panic。两线分属两坐标系(危险线=任务真 sp
  系;告警线=守卫读点系;打印链在其下第三层),勿混比。
- lowdemo 重锚:stop=lim+RT_GUARD_LINE+256=lim+896;warn 行**整
  行先组后单发 rt_puts**(评审:三段三次锁窗可劈 needle,亦压
  ~90B 链深)。本 build 探针实测 warn 打印 400、打印链底 ~240,
  magic 不误伤;恰一次 warn。
- 评审战果:B1 两处 blocker 经 verify 皆判 REFUTED——单行组串+
  停点重锚先于 verify 落码,修真被反向确认。

## C 块:console 延迟冲刷([54] 残余收编)

- 病灶:chardev 分块缝(块间隙客恰停泊、双环皆空)→泊位即时冲
  刷吐半行回显→互插者落缝=回显 needle 碎(站二十二风暴实测
  23/60 回显碎)。
- **延迟化**:泊位不再即时冲,武装 `flush_at=CNTPCT+20ms`
  (CNTPCT/CNTFRQ EL2 直读无陷=**零宿主时钟手术**——站二十二
  定性的"需 100Hz 宿主钟"被此设计绕开);冲刷由泵入口扫描执行。
- **时间基修真(评审纠偏)**:扫描的真正驱动=CPU0 宿主壳忙自旋
  (shell_run 每迭代一圈 sched_pump,µs 级,boot 序即恒在)——
  **不是** vm0 100Hz tick(vm0 未建/已杀期扫描照常;pump_cpu 无
  扫描);长量子期间扫描停摆 ≤1 量子,fire 复验下迟冲无害。
- **fire 时刻复验(评审 CONFIRMED major,[54] 第二雷复活面)**:
  武装时刻的静默判(全帧泊位+RX 环空)延拓到 fire 时刻——陈旧
  武装(泊后自醒长跑、死线已过)在行在途时拦腰冲出半行=新路径
  共享旧状态;不满足**保留武装**留待下一泵入口复扫,行 '\n'
  收口后自然 no-op。arm 写与 fire 判-清**同入 console_lock**
  (评审 minor:无锁清零可吞并发武装);vmconsole 双向切换/
  escape/vm_finish/owner 落位四即冲口同步熄武装(评审 c 场景)。
- 判据:echo 风暴门 **[65],真并行窗**(vm2 靴流正冲、vm1 前台)
  10 发唯一 token **10/10 连续**(延迟化前 23/60 撕,探针实测
  延迟化后 0 撕)。**评审迁窗定谳**:初版 [51] 落点 owner=host
  且 vm2 未建——needle 由宿主壳自产,门恒绿空转(假见证门);
  终落 [64] 真并行判据后。smpdemo [36] 就地强化为 vm0 双帧
  行完整性 needle(连续型正则 vs 子串数,撕裂即红)——fire
  复验的正向见证面。>20ms TCG 停顿窗=残余,观察哨记档。
