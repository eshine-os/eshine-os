## 0. 机制

- **musl fork 契约**(sys_clone 转发):aarch64 号面无 __NR_fork
  (asm-generic 64 位段不定义),musl 的 fork()/vfork() 都=
  clone(SIGCHLD,0)——零线程旗=进程复制语义,sys_clone 转发 sys_fork
  (RT_CLONE_VFORK 宏面加入,即便出现也降级 fork 记档;musl 自身
  vfork 即此形)。站 42 的 clone 只认线程族(NEEDS=VM|THREAD)——
  musl fork 全拒 -22,"sh: can't fork" 定谳(busybox ash=仓内首个
  fork 的 musl 进程;hello/beat/initmark 全不 fork=14 站潜伏缺口)。
- **子继承父 tpidr**(sys_fork 补角):站 35 线程面 SETTLS 有初值,
  fork 面缺——孙(ash fork 出、不 exec、直跑 busybox 代码)槽=0,
  切换载入,__pthread_self=tpidr_el0-0xA4 → far=-0xA4 野访(站 64
  core 文件把死者三元送上门:elr=busybox+0x24058 反汇编=mrs
  tpidr_el0+sub 0xA4 内联 __pthread_self 调用点定谳)。修=ct->
  tpidr_el0=rt_cur->tpidr_el0(vec.S 切换存还链既有,站 35 机器)。
- **bsh 命令**(bsh <cmd...>=busybox sh -c 一次性子壳):判据面=
  ash 解析器内建(echo+变量赋值展开 "V=x; echo $V");printf=applet
  走 execve=ENOSYS 127 记档(exec=用户态 loader 红线,ash 不识);
  $((算术))=busybox 构建禁用记档。
- **无参交互 stdin 流模式=深水挂账**(v0 诚实边界):ash 无参→fork
  孙→vm0 全停。取证链:串口零输出 90s(心跳停)+宿主热键不响应
  (全机非 vm0 单面)+QEMU 0% CPU(四核 wfi 非自旋)+gdb stub(HMP
  monitor)定格:CPU#0 宿主壳 PC=pump_run_vcpu+0x2a8(mrs cntvct_el0
  前拍)=泵活但 vm0 tick 断——孙交互/tick 链双深水未定谳,专站收
  (参考实现无先例;boot 挂脸族 58 未定谳亦在同一深水区,可能同源)。

## 1. 战雷

- **三靴三种死相的取证纪律**:挂 A(initmark 后卡)→基线 3/3 绿排除
  改动→挂 B(beater 段卡=58 族波动)→**挂 C(panic elr=0xa5a5 毒跳
  才是真雷信号)**——非确定挂脸与确定性 bug 混窗时,**panic/野访面
  优先于静默挂**(静默挂族有 58 基线,新代码的 panic 无基线)。
- **sed 修场景 JSON 反斜杠雷**:$((6*7)) 在 sed 模式里直写,替换
  未生效静默过——**改 JSON 场景用 Edit 工具逐句改,sed 只做纯文本
  直行**(本站两犯:printf→arith→变量三次改场景,前两次 sed 假成功)。
- busybox 构建面:$((算术)) 禁用(CONFIG_FEATURE_SH_MATH off)、
  printf=applet 非内建——**判据面选内建前先验 busybox 构建配置**
  (ash 内建可靠面:echo/变量赋值/展开/分号序列)。
