## 1. A 块:rtos 壳心跳按需化(用户令①)

### A1 机制

- 现状:heartbeat_task 每 50 tick 打 `rtos: alive tick=N`,
  站二十 HVC#5 前台门控——vmconsole 0 后(前台)每 0.5s 一行
  刷屏,交互期噪音(用户抱怨的对象)。
- **新语义:心跳只在壳自主睡时说话**——`hvc_fg() && shell->
  state == RT_SLEEP` 才打印。判别器已天然成立:**at-prompt=
  RT_BLOCK**(rt_block_rx,rt_task.c:136)/`sleep N`= RT_SLEEP
  (rt_task.c:113)——提示符等待与输入阻塞不说话,自主长睡才
  说话("心跳是替睡死的壳报平安,不是打扰正用的人")。
- shell 任务指针:guest_main 建壳时存静态指针(rtos.h 无需
  新面,同 TU)。
- **`hb` 命令**(按需打印):rtos 壳新增,打印一行现行
  `rtos: alive tick=N`(格式不变,HB-strip/判据正则兼容)——
  "可以输入命令再打印"的字面实现;手动走查与门禁注入共用。
- HVC#5 保留(心跳仍用);`sleep 3` 窗口([24] 判据)语义
  不动:壳 RT_SLEEP → 心跳照印,任务级并发活证保全。

### A2 判据改动(不增门,就地强化)

- **[24] 不动**:sleep 3 窗内心跳行依旧 spontaneous;
- **[69] 改 hb 注入**:窗口内(仍 vm0 前台、vm2 靴流正冲)
  由门禁注 `hb`×3(0.5s/2.5s/4.5s,窗 5s;末发有效宽限 ≈2.5s
  ——[69]/[76] 预算分司两级:注入响应/完整命令执行,不矛盾),
  断言 ≥2 行 alive 且 tick 值严格递增(regex 抽取)——从
  "被动心跳夹行"升级为"主动交互活证"(恰好也是 [41] 输入
  路径的见证面)。**失败分诊**:tick 冻结(相邻 hb 同值)=
  [41] vtimer 侧残余(§5),非输入不变量破;
- **[47] 就地强化**:token 窗断言**零 spontaneous alive 行**
  (提示符安静的用户承诺成为判据);
- **[37] 语义保全(评审抓出)**:ipidemo 回合循环原在壳语境睡
  (rt_sleep_ticks 使壳过 RT_SLEEP)——心跳按需化后 demo 期
  壳每拍夹心跳行,恰是用户令①要除的刷屏;移入独立任务
  ipimain,壳即回提示符(静默),判据 needle 全由任务打印,
  零迁。

## 2. B 块:输入唤醒不变量(用户令②根因,[41] 家族脸 #5)

### B1 两洞名状(检查面+实测双定谳)

- **洞①(分类门)**:shell.c 推环直通唤醒只认
  `wait_state==1 && wait_reason==VCPU_WAIT_RX`;而泊位分类
  (vm.c:664)按 vtimer_ctl&1 归 TIMER——**真 Linux 壳恒
  armed 恒 TIMER**(trail ev1 a=1 实证),RTOS 客 tick 恒在亦
  TIMER。旧门下输入只能等客自家 vtimer:vm0 ≤10ms 尚可,
  vm2 深睡=秒级~永不([76] 30s/探针 40-90s/用户卡顿)。
  WFI"任何 pending 中断即醒"语义只建模了 RX 分类一半。
- **洞②(出口窗竞态)**:推环唤醒检查与停泊出口窗竞态——
  读到 wait_state=0(退出在途)→不醒→随后泊定→环内字节
  无主,唤醒源只剩客自家 vtimer。

### B2 修法(输入⇒runnable 不变量)

- **推环侧**:唤醒去 reason 门——`wait_state==1` 即翻
  runnable(推环后环必有数据;醒后泵入口注入 LR1 消费,
  RXIM 使能面照旧门控注入)。同律 poke_cpu1 保留。
  **评审 Dekker 补**:环写与对侧 wait_state 写皆普通存取,
  无障下双侧皆可读到旧值同拍丢唤醒——推环侧存后读前
  `dmb ish`(push 的锁内 release 只序先前访存,不序后续
  的 wait_state 读,勿倚锁)。
- **泊位侧**:泊位落定(分类+trail 后)复查——owner 帧
  且**过泵入口复查网同门**(vuart_rx_irq_ready+vgic 使能,
  非裸 has_data——不看使能面的复查会造泵热自旋:客无
  RXIM 可取时泊-醒 µs 级死循环烧核,过门即真有可取事件,
  自愈有界)→ 翻回 runnable(洞②关窗;同核序贯,泵下一圈
  即取)。**Dekker 对偶**:wait_state 写与环读之间 `dmb ish`。
  事件码 **ev16** 专用(a=(id<<4|vi),b=reason)——勿复用
  ev1(与站二十 [41] 探针契约冲突,新旧取证不可比)。
- 不变量成立后:console 输入路径与 vtimer 健康度**解耦**
  ——[41] 家族的 vtimer 侧真凶(五站五脸未根除的存档案)
  仍可致静默 tick 停摆/心跳断流,但**交互永不再蒸发**;
  vtimer 根因留专站(残余记档,观察哨续档)。

### B3 判据(不增门,就地收紧)

- **[76] 超时 30s→10s**:该门形状=大 dump 后泊位+立即输入
  (正是脸 #5 的复现器);健康 ~1s,旧脸 30s+——10s 上界
  是诚实见证(收紧=判据只增不减的真强化)。
- [73]/[74]/[75] 同路径自然受益,不动。

## 2.5 战况追加(实现期两雷,评审+门禁自抓)

- **延迟冲刷相位活锁([19]/[53] 门禁自抓)**:站二十三 C 块
  每泊重臂 flush_at=+20ms,对 10ms 拍客(RTOS tick)恰 2:1
  相位锁死——fire 时刻必撞下下拍唤醒边界(未泊跳过),再泊
  又先重臂后扫描=尾字符永久滞环([19] 空格 5/5 确定性复现;
  站二十三此门一直绿全靠心跳打印首字符顺手冲掉滞留字节的
  意外救场,A 块静默心跳后活锁裸露)。修:**只首次武装**
  (flush_at==0 才臂;已武装含过期不推迟——过期死线保留,
  下一泊定瞬间 fire 即收,~200µs)。
- **fg 前置发射撕缝([53] 双轮定谳)**:fg 路径每字符先冲
  上一字符(站二十二逐字符透传残骸,与"整行原子"宣称矛盾)
  ——prompt 类半行=5 字符已流+末字符滞环,20ms 冲刷窗=
  互插者落缝之窗([53] 实测 "rtos>[vm1] vm1> " 撕裂,needle
  永不连续)。修:**撤前置发射**——fg 字符全量入环,'\n' 或
  泊位冲刷整段锁内原子;bg→fg 迁移残留半行由 owner 切换口
  先行冲刷保(vmconsole/escape/死亡三口已立,前置发射于彼
  场景冗余);键回显 UX 由 20ms 延迟冲刷保(站二十三 C 定标)。

## 3. C 块:进场 flush 幸存者收尾(站十九不变量补完)

- vcpu.c:69 进场全量 `tlbi vmalls12e1is` 幸存(站十九只门了
  vttbr 侧那发):hcr 写后惯例 flush,HCR 不涉翻译缓存,无事
  可做——退役,只留 isb。熄旧表归 last_vttbr 对比,槽位复用
  归 vcpu_flush_all_tables(不变量自洽)。**评审抓出**:该
  清零循环是站十九三核遗物,CPU3(vm0.vcpu1 专泵,站二十)
  记账永不清——同值重建页表的槽位复用会把旧缓存泄给新客,
  扩到四核。
- **诚实账(判负实验)**:本站曾假设此行是卡顿总根(flush
  风暴论),实测判负——E4 echo 900 字符(~1800 MMIO 陷阱,
  内联不过 vcpu_run)0.00s 反证 + 健康轮 fp 0.04s + 修后探针
  无改善,证明 QEMU 此 tlbi 路径实为廉价。保留退役(不变量
  正确性+站十九注释自洽),收益记"无实测增量"。
