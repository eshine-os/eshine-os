# 站四十六:崩溃取证链(crash 环+寄存器面+用户帧链)

**日期**:2026-11-02 | **序**:批令 43-48 第五站 | **基准**:参考实现
coredump/取证面白描;站 29"野访终态面留边"翻案日。

## §1 问题

- 站 29 契约:EL0 野访(无 VMA 覆盖)=**全系统 rt_panic**——
  一个用户进程的死亡是全 VM 的死亡。站 38 已给信号默认动作
  走 exit 链,但硬件异常面仍全灭。取证角度:死者无遗照
  (寄存器/帧/野址不留档),死后无从复盘。
- calltrace(站 43)只回溯 EL1 栈;EL0 死者的用户帧链无人走。

## §2 v0 站内形状(契约决定)

- **野访翻案**:EL0 无 VMA 野访 → **进程退出+取证记录**
  (code=139=128+11,SIGSEGV 面),走 sys_exit 死者本人语境
  同链(fd 清+线程群扫+ZOMBIE;与信号终局同机器)。
  **EL1 panic 面不动**(内核 bug 仍全系统驻车=正确的保守)。
- **crash 环(rt_crash.c)**:2 槽环形记录 {tick,pid,任务名,
  esr/elr/far 三元(信号路径无硬件三元=0),code,x0-x5 寄存器
  面,**用户 x29 帧链前 4 帧**}。参考实现 coredump 白描的站内
  形状:ELF 核文件落盘不可为(ramfs=只读 rodata 服务器,
  文件面=站 33 后弧)——**内存记录+shell 倾倒**=v0 诚实形,
  记档差异。
- **用户帧链**:死者帧 x29(帧偏移 24+8×29)起走;**窗门**
  (identity 0x40200000-0x40400000 ∪ mmap 0x40C00000-0x40E00000)
  + **映射门**(逐读前 l2 PTE present 查——坏栈不再把取证
  变成 EL1 二次事故)+单调门。4 帧保险丝。
- **记录点两处**:EL0 野访终态(硬件三元全)+信号默认动作
  (esr/elr/far=0,code=128+sig)。僵尸面(crashinfo)倾倒全部。

## §3 判据(crashdemo)

- fork 子:野读 0x4F000000(窗内两窗皆无 VMA)→ 子死:
  父收尸 **code=139** → crashinfo:记录含 **far=0x4f000000**
  +任务名+帧数>0。全系统活(父照常打印收尸=崩溃不再连坐)。
- 门禁:[125] crashdemo(收尸 139)+[126] crashinfo(far 面+
  frames)。

## §4 非目标(记档)

- crash 后重启链(reboot 面)。
- 多任务并发崩溃合并取证。
